# agendamento-rotacao-camare

## Descrição do Problema
Sistema para gerar a escala de plantão dos técnicos de radiologia para a semana.

## Requisitos
- Alternar os turnos de manhã, tarde e noite
- Garantir que cada técnico tenha no máximo 2 turnos por dia
- Exibir os horários e os técnicos

## Exemplo de Uso
Chamar a função gerarEscala com uma lista de técnicos

Saída:
Dia 1: Manhã - Ana, Tarde - Bruno, Noite - Carla
Dia 2: Manhã - Bruno, Tarde - Carla, Noite - Ana
